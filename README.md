# Tradução PT-BR — Dragon Ball Z: Budokai Tenkaichi 3 (PS2)

![Dragon Ball Z: Budokai Tenkaichi 3 - Capa](https://static.wikia.nocookie.net/dragonball/images/5/5a/Capa-dbz-sparking%21-meteor.webp/revision/latest?cb=20240612001520&path-prefix=pt-br)

Patch de tradução para Português Brasileiro do jogo **Dragon Ball Z: Budokai Tenkaichi 3** (PlayStation 2), feito por fã para fãs.

Traduz TODO o texto do jogo: menus, tutoriais, nomes de itens e golpes, biografias da Central de Dados, história, etc. O jogo é 100% original e não possui dublagem — o áudio é o mesmo da versão americana, sem nenhuma alteração.

## Conteúdo do repositório

* `DBZ BT3 (PT-BR).xdelta` — o patch de tradução (formato xdelta)
* `LEIA-ME.txt` — instruções completas de instalação (em português)

## Requisitos

* ISO original e limpa do jogo **Dragon Ball Z: Budokai Tenkaichi 3** Americana (SLUS-21678) de PS2, com 3.020.816.384 bytes (2,81 GB). Sem outras modificações
* [Delta Patcher](https://github.com/marco-calautti/DeltaPatcher) — ferramenta gratuita para aplicar o patch

## Como instalar

1. Baixe o [Delta Patcher](https://github.com/marco-calautti/DeltaPatcher/releases) para o seu sistema operacional
2. Baixe o arquivo `DBZ BT3 (PT-BR).xdelta` deste repositório (aba Releases ou direto na lista de arquivos)
3. Abra o Delta Patcher, selecione o modo Apply Patch
4. Selecione o `DBZ BT3 (PT-BR).xdelta`, sua ISO original e o nome do arquivo de destino
5. Clique em Apply e aguarde a conclusão

Instruções detalhadas passo a passo estão no arquivo `LEIA-ME.txt`.

## Aviso legal

Este repositório não distribui nenhum arquivo do jogo original. O patch apenas modifica bytes de uma ISO que o usuário já possui legalmente. Nenhum conteúdo protegido por direitos autorais da Bandai Namco/Spike/Toei Animation está incluído aqui.
